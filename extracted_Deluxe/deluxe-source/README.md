# DELUXE — редактируемый проект

Java-исходники восстановлены из `DELUXE.jar` версии 38.1.5 для **Minecraft 1.21.11 / Fabric**. Проект собирается из `.java`; исходный мод не подключается как бинарная зависимость. Оригинальный JAR сохранён рядом с проектом.

Откройте эту папку как Gradle-проект в IntelliJ IDEA и выберите JDK 21 или новее. Первый импорт скачает Minecraft, Yarn, Fabric и Gradle; требуется интернет. Используется Gradle Wrapper, отдельно устанавливать Gradle не нужно.

```powershell
.\gradlew.bat build
.\gradlew.bat runClient
```

Готовый мод и JAR с исходниками появляются в `build/libs`. Для установки мода нужен Fabric API для Minecraft 1.21.11. Обычный запуск разработки хранит миры и настройки в `run`; путь можно изменить через `-PclientRunDir=другая-папка`.

Проверка восстановленной Java-логики включена в `build`. Её можно запустить отдельно:

```powershell
.\gradlew.bat recoveryChecks
```

`src/main/java` содержит 544 файла. Ресурсы, шрифты, изображения, шейдеры и звуки находятся в `src/main/resources`. Карта проекта и ограничения восстановления описаны в [SOURCE_GUIDE.md](SOURCE_GUIDE.md).

Если на Windows с JDK 25 запуск Gradle падает из-за пути временных файлов с кириллицей, задайте существующую временную папку с латинским именем:

```powershell
New-Item -ItemType Directory -Force C:\JavaTemp | Out-Null
$env:JAVA_TOOL_OPTIONS = '-Djava.io.tmpdir=C:/JavaTemp -Djdk.net.unixdomain.tmpdir=C:/JavaTemp'
.\gradlew.bat runClient
```

Исходные имена после обфускации невозможно восстановить буквально. Названия классов и основного API подобраны по коду и вызовам; часть внутренних методов, полей и локальных переменных ещё сохраняет технические имена. Это редактируемая и собираемая реконструкция, а не оригинальный репозиторий автора.

Чит-функции на серверах могут нарушать правила сервера и условия сервиса и привести к бану.
