# Skycore — исходники клиента

Подпись профиля, HUD и заголовок окна:

t.me/goonglang t.me/rosetkaqqe t.me/movefix

Minecraft 26.2, JDK 25, Fabric Loader 0.19.5, Fabric API 0.156.0+26.2.

## Запуск

Установите JDK 25, откройте PowerShell в папке проекта и выполните:

```powershell
.\gradlew.bat runClient
```

Для сборки: `.\gradlew.bat build`.

Игровой ник для runClient: `goonglang`. Подписи клиента содержат все три Telegram-ссылки; игровой ник не содержит пробелов и слешей.

Gradle Wrapper 9.7.1, Loom 1.18.3. При первом запуске скачиваются недостающие зависимости и игровые ресурсы. Настройки клиента создаются в `run/skycore`.

В архиве находятся Java-исходники, ресурсы, Gradle Wrapper, конфигурация сборки и необходимые сторонние библиотеки с лицензиями. Рабочие настройки, аккаунты, логи, отчёты восстановления, кэши и сборки клиента в архив не включены.

Это восстановленные исходники: часть имён и структуры получена декомпиляцией. Полного антивирусного заключения нет; защита и выявленные отправщики данных были исключены при восстановлении.
